Privacy Policy

Last updated: March 2026

This privacy policy applies to services provided at qingjingxin.org, including the PPTX Expert API and any Custom GPTs that use it.

1. Operator

These services are operated for personal and non-commercial use. The API and related tools run on infrastructure under the control of the operator of qingjingxin.org.

2. Data involved when you use the Custom GPT

  • Conversations: Your chats with the Custom GPT are processed by OpenAI according to OpenAI’s privacy policy. We do not receive or store the content of your conversations.
  • API requests: When the GPT calls our API (e.g. to create a presentation), we receive the data needed for that request (such as title, topic, number of slides). We do not receive your OpenAI account details or identity.
  • Generated files: Created PPTX files are stored temporarily on our server and are available via time-limited download links. We do not use them for purposes other than delivering the file to you.

3. Logs and retention

We may log request metadata (e.g. time, endpoint, success/failure) for operation and security. We do not sell or share this data with third parties. Logs are retained only as long as needed for these purposes.

4. Security

API access is protected by authentication (API key). We use standard practices to keep the service and data secure; we do not guarantee absolute security of data in transit or at rest.

5. Your choices

You can stop using the Custom GPT and our API at any time. We do not track you across other sites or services.

6. Changes

We may update this policy occasionally. The “Last updated” date at the top will be revised when we do. Continued use of the service after changes constitutes acceptance of the updated policy.

7. Contact

For questions about this privacy policy or the service, please open an issue or contact the repository maintainer via the ppt-expert project on GitHub.
